# on-the-beat (정박 체크)

메트로놈에 맞춰 쳤는지 폰 마이크로 재는 웹앱. `index.html` 한 파일로 돌아간다.

주소: https://kiithroen.github.io/on-the-beat/

## 쓰는 법
1. 안드로이드 크롬에서 위 주소를 열고 마이크 권한 허용
2. 지연 보정: 보정하기를 누르고 6초 조용히 둔다
   - 유선 이어폰을 쓸 거면 이어버드 한쪽을 폰 마이크 구멍에 대고 보정
3. 템포·박자·채점 단위를 고르고 시작. 1마디 카운트인 뒤 채점

## 주의
- 블루투스 이어폰은 지연이 들쭉날쭉해서 비권장
- 출력(스피커/이어폰)이나 클릭 음량을 바꾸면 다시 보정
- 마이크가 없는 PC에서는 화면 확인만 가능

## 동작 방식
- 클릭은 4kHz 삐 소리(첫 박 4.8kHz)
- 타격 감지는 AudioWorklet 안에서 스펙트럼 플럭스로 한다
  - 기타 대역(70–1500Hz)과 클릭 대역(3–6.5kHz)을 따로 본다
  - 스피커로 클릭을 틀어도 친 음으로 잡히지 않는다
- 친 음은 가장 가까운 채점 칸에 붙여 오차(ms)를 낸다. 안 친 칸은 감점하지 않는다
- 음 이름: 타격 직전·직후 85ms의 4096점 스펙트럼 차이(새로 생긴 에너지)에서 배음 합이 가장 큰 음(E2~C6)을 고른다. 한 음씩 칠 때 맞고, 화음은 한 음만 잡힌다
- 설정, 보정값, 최근 30회 기록은 브라우저(localStorage)에 저장된다
